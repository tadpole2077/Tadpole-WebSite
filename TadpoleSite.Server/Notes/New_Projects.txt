Local Debug Process
=================================================

- Angular.json Proxy settings
  These settings are found under "serve"" section, used only for debug within local dev env.  Port can be custom
          "options": {
            "proxyConfig": "src/proxy.conf.js",
            "port": 63612
          }
  But must match the port defined in project file : TadpoleSite.server.csproj
    <SpaProxyServerUrl>https://localhost:63612</SpaProxyServerUrl>
  
  And also match port used in TadpoleSite.client\.vscode\launch.json , which controls what page URL is loaded with the selected debug browser (chrome, brave etc).
    "url": "https://localhost:63612"



- Profile, trigger a startup >> "ASPNETCORE_HOSTINGSTARTUPASSEMBLIES": "Microsoft.AspNetCore.SpaProxy"
    This is the SPA proxy launch page. 
    Microsoft.AspNetCore.SpaProxy.SpaProxyLaunchManager

- Proxy Dev Config Settings:
    Angular.json >> serve > configurations > "proxyConfig": "proxy.config.js",

- On successful load  should redirect to https://localhost:[proxy port defined in angular json]
